# Security Policy

## Reporting a vulnerability

Perfect AuPair is no longer an active service and has no maintained public deployment.

If the published repository contains a credential, personal data, or a serious vulnerability relevant to the source code, please use the repository's private vulnerability reporting feature. Do not disclose it in a public discussion or pull request.

Include:

- the affected route or component;
- clear reproduction steps;
- the potential impact;
- any suggested remediation;
- a safe way to contact you for follow-up.

Do not access, alter, download, or retain another person's data while testing. Do not perform denial-of-service testing, automated high-volume scanning, social engineering, or destructive actions.

Reports will be reviewed when practical. Please allow a reasonable remediation window before any public disclosure.

## Secrets

The repository must contain only empty or clearly local/example environment values. If you discover a credential or personal data in the repository, report it privately and do not use it.
